# Philadelphia, building by building

An interactive 3D map of every building in Philadelphia, coloured by the year it was built. Modelled on the Amsterdam edition at https://stop-token.com/lab/amsterdam/.

The site is static: open `index.html` through any web server, or visit the GitHub Pages site for this repository.

Data: City of Philadelphia Office of Property Assessment and building footprints (OpenDataPhilly); Overture Maps Foundation.
